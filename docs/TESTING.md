# دیدن دمو و پیدا کردن ایراد

## سطح ۱ — بدون بک‌اند (۲ دقیقه)
در `frontend/.env`: `VITE_MOCK_MENU=true` ← `pnpm dev` ← مرورگر:
- `http://localhost:5173` منوی عمومی
- `http://localhost:5173/admin` پنل (هر ایمیل و رمزی قبول می‌شه؛ داده‌ها با رفرش برمی‌گرده به حالت اول)

## سطح ۲ — با بک‌اند واقعی
۱. دیتابیس + `config.php` + ادمین (مراحل `README.md` ریشه).
۲. بدون Apache: `php -d upload_max_filesize=8M -d post_max_size=10M -S 127.0.0.1:8080 -t backend backend/tests/dev-router.php`
۳. در `frontend/.env`: `VITE_MOCK_MENU=false` و `API_PROXY=http://127.0.0.1:8080` ← `pnpm dev`.
۴. `python3 backend/tests/smoke.py http://127.0.0.1:8080 backend/uploads` ← باید «0 failed» بده.

## سطح ۳ — روی گوشی خودت
`pnpm dev --host` ← آدرس `http://<IP-کامپیوتر>:5173` رو روی گوشی (همون وای‌فای) باز کن. برای ورود به پنل، همون origin رو به `allowed_origins` در `config.php` اضافه کن.

## سطح ۴ — PWA (باید build باشه، نه dev)
`pnpm build && pnpm preview` ← `http://localhost:4173` ← DevTools ← Application:
- Cache Storage: فقط فایل‌های build؛ **هیچ `/api` یا `/uploads`** نباید باشه.
- قیمت رو در پنل عوض کن و منو رو reload کن؛ باید بلافاصله جدید باشه.
- Network ← Offline ← reload: پوسته باز بشه ولی منو «خطا + تلاش دوباره» نشون بده، نه داده‌ی قدیمی.
- نصب روی صفحه‌ی اصلی فقط روی HTTPS یا localhost کار می‌کنه.

## چک‌لیست دستی (هر مورد ایراد پیدا کرد یادداشت کن)
**منو:** RTL درست؟ اعداد فارسی؟ جستجو با «ك/ي» و ارقام عربی؟ آیتم ناموجود کم‌رنگ؟ دسته‌ی غیرفعال/خالی نیست؟ اسکرول پنل دسته‌ها؟ حالت تیره؟ قطع اینترنت؟
**پنل:** لاگین اشتباه ۶ بار ← قفل؛ تغییر قیمت با لمس؛ سوئیچ موجودی؛ ▲▼ ترتیب؛ آپلود عکس بزرگ گوشی؛ تعویض/حذف عکس؛ خروج با ناسازگاری فرم (هشدار ذخیره‌نشده)؛ حذف دسته با آیتم؛ تغییر رنگ برند و پیش‌نمایش.
**ابزارها:** Lighthouse موبایل (هدف: Performance ≥ 90، Accessibility ≥ 95)؛ تب Network (حجم عکس‌های منو)؛ فقط‌کیبورد (Tab) روی همه‌ی صفحه‌ها.

## گزارش ایراد
چه کاری کردی ← چه انتظار داشتی ← چی شد (+ اسکرین‌شات، Console، و خط آخر `backend/api/storage/logs/app-*.log` برای خطای ۵۰۰).

## دمو آنلاین؟
فقط خروجی `pnpm build` (استاتیک) رو می‌شه روی هر هاست استاتیک گذاشت، ولی بدون PHP/MariaDB منو و پنل داده ندارن. پس برای «دمو واقعی» یا اجرای محلی، یا یه هاست PHP ارزان (فاز ۱۲ `OPERATIONS.md`).
