# راهنمای صاحب کافه
آدرس پنل: `https://آدرس‌منو/admin` — با ایمیل و رمزی که بهت داده شده وارد شو.

**تغییر قیمت:** تب «آیتم‌ها» ← روی قیمت بزن ← عدد جدید ← Enter. بلافاصله در منو عوض می‌شه.
**تموم شدن یه آیتم:** سوئیچ کنار آیتم رو خاموش کن (در منو «ناموجود» نشون داده می‌شه). دوباره روشنش کن تا برگرده.
**آیتم جدید:** «آیتم جدید» ← دسته، نام، قیمت، (توضیح و عکس) ← ذخیره.
**عکس:** از گالری گوشی انتخاب کن؛ خودش کوچیک و بهینه می‌شه. بهتره عکس افقی و روشن باشه.
**ترتیب:** با ▲ و ▼ کنار هر آیتم یا دسته.
**دسته:** تب «دسته‌ها» ← اضافه، تغییر نام (روی نام بزن)، خاموش کردن موقت، حذف (آیتم‌هاش هم حذف می‌شن!).
**تنظیمات:** نام، تلفن، ساعت کاری، اینستاگرام (فقط نام کاربری)، لوگو، رنگ برند. رمز رو از همین‌جا عوض کن.
**مشکل داشتی؟** نوع مشکل + اسکرین‌شات بفرست. رمز رو فراموش کردی؟ به پشتیبان بگو.
